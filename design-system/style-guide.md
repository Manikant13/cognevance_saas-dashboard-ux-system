# Style Guide

## Components
| Component | Variants | States |
|-----------|----------|--------|
| Button | Primary, Secondary, Ghost, Danger | Default, Hover, Pressed, Disabled |
| Input | Text, Select, Search, Date | Default, Focus, Error, Disabled |
| Table | Sortable, Selectable | Default, Hover, Selected |
| Card | KPI, Chart, Info | Default, Hover |
| Chart | Line, Bar, Pie | Default, Hover tooltip |
| Modal | Confirm, Form | Open, Close |

## Micro-interactions
- Button hover: color change in 150ms
- Card hover: slight lift with shadow
- Loading: skeleton screens
- Theme toggle: smooth 200ms transition

## Usage Rules
- Use one primary button per section
- Keep spacing on the 8px grid
- Use the same icon set everywhere
