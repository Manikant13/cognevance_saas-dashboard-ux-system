# Enterprise SaaS Dashboard UX System

## Project Objective
Build a scalable enterprise-level dashboard design system with advanced UX workflows, including light/dark themes and accessibility support.

## Tools Used
- Figma (design system, screens, prototype)
- FigJam (architecture and workflows)
- Contrast checker (accessibility)

## Workflow
1. Designed the dashboard architecture
2. Created reusable components and a design system
3. Designed advanced dashboard and analytics layouts
4. Added dark/light themes and accessibility features
5. Built an interactive prototype with micro-interactions
6. Performed a UX audit and usability analysis
7. Documented the design system, workflows, and style guide
8. Prepared the final case study presentation

## Design System Summary
| Element | Light Theme | Dark Theme |

| Primary | [#2563EB] | [#3B82F6] |
| Text | [#111827] | [#F1F5F9] |
| Success / Warning / Error | [#16A34A / #F59E0B / #DC2626] | same |

## Accessibility
- Text contrast meets WCAG AA (4.5:1)
- Visible focus states
- Minimum text size 14px
- Color is never the only indicator
