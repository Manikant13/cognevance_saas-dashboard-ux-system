# Accessibility Checklist

- [x] Text contrast ratio of at least 4.5:1
- [x] Visible focus states on all interactive elements
- [x] Minimum text size of 14px
- [x] Color is not the only indicator (icons and labels added)
- [x] Touch and click targets at least 40px
- [x] Dark and light themes both pass contrast checks
- [x] Clear error messages
