# Dashboard Architecture

## User Roles
| Role | Access |
|------|--------|
| Admin | Full access, user management, settings |
| Manager | Analytics, reports, team view |
| Viewer | Read-only dashboards |

## Navigation Structure
- Sidebar: Overview, Analytics, Reports, Users, Settings
- Top bar: Search, Notifications, Theme toggle, Profile

## Main Modules
1. Overview: KPI cards, recent activity
2. Analytics: charts, filters, date range
3. Reports: table, export, schedule
4. User Management: list, roles, invite
5. Settings: profile, preferences, theme

## Key User Flows
- Admin invites a new user
- Manager filters analytics and exports a report
- Viewer checks the overview
